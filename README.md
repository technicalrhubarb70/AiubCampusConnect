# 🎓 AIUB CampusConnect

### Connecting AIUB students, one course at a time.

</div>

This is a project made by **Rafit Rahad** and **Kazi Ayesha** for our **Web Technologies course at AIUB**.

**AIUB CampusConnect** was built around a simple idea: university life becomes a lot easier when students can find the right people to help them.

For students taking **open credit courses**, finding someone who has already completed the course, understands the faculty, knows the common struggles, or can provide tutoring can be surprisingly difficult. Instead of depending on random posts or asking around, AIUB CampusConnect brings students and student tutors together in one place.

Students can search for tutors based on **courses and skills**, explore tutor profiles, and communicate directly with them. At the same time, students who are confident in a subject can create tutor profiles and help others while sharing what they know.

The goal is to make academic support within AIUB a little more accessible, organized, and student-friendly — basically, **students helping students survive university together.**

# ✨ Main Functionalities

## 🔐 1. Registration & Login

Users can create an account and securely log in to AIUB CampusConnect.

**Features:**
- Student registration
- User login
- Input validation
- Session-based authentication


## 👤 2. Student Profile

Students can maintain their personal information and use their account to access the platform.

**Features:**
- View student profile
- Manage account information
- Access student-specific features

## 🎓 3. Tutor Profile

Students who want to tutor others can create their own tutor profile.

**Features:**
- Create a tutor profile
- Add courses
- Add skills
- Provide tutoring information
- Set profile visibility

## 🔎 4. Find a Tutor

Students can search for suitable tutors without having to depend on random posts or mutual connections.

**Features:**
- Browse available tutors
- Search by course
- Search by skill
- View tutor information

## 📚 5. Course & Skill Based Search

CampusConnect helps students narrow down tutors according to exactly what they need help with.

For example:

> Need help with **Web Technologies**?  
> Search the course and find students who can tutor it.

## 💬 6. Messaging System

Students can communicate directly with tutors through the platform.

**Features:**
- Send messages
- Receive messages
- Student-to-tutor communication
- Keep academic communication within the platform
